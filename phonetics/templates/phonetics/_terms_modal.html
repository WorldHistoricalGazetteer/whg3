{% comment %} Contribution terms, as a modal fragment (SG, 2026-09-07). A bare fragment: no `extends`, and it supplies its own .modal-header, because whg-modal.js only prepends the default header when the response has none. ⚠ The form posts NORMALLY to the full-page terms view rather than over AJAX. That is deliberate. Agreeing is a once-per-contributor act that must be recorded before anything else happens, and a normal POST means the redirect, the `next` round trip and the "you agreed on …" state all work with no JavaScript involved. An AJAX submit here would add a second code path through the one gate the app must never get wrong. The standalone page at /phonetics/terms/ stays, and is what this posts to. It is also the fallback whg-modal.js offers ("open it in a new tab") if the fetch fails. {% endcomment %}
